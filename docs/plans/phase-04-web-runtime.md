# Phase 04 — Web runtime

## Objective
Provide a useful Node-independent server runtime.

## Tasks
- URL APIs;
- encoding;
- Abort APIs;
- EventTarget baseline;
- Web Streams;
- TCP;
- Hyper HTTP/1 + HTTP/2;
- rustls TLS;
- Headers/Request/Response;
- fetch;
- WebSocket;
- WPT adapter;
- body/socket quotas.

## Acceptance
Secure Web-standard API server + fetch client run with scoped network grants.

## Performance
Establish first Node/Deno/Bun comparative server benchmark, clearly versioned.
