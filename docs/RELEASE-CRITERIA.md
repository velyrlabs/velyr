# Release criteria

## Preview
- architecture may change;
- no compatibility guarantees;
- security invariants already enforced.

## Beta
- CLI/config freeze candidate;
- permission model stable enough for review;
- runtime has no known critical permission bypass;
- compatibility dashboard published;
- benchmark regression CI enabled.

## Stable 1.0
- release gate from ROADMAP satisfied;
- coordinated disclosure process;
- supported platform matrix;
- conformance results published;
- known deviations documented;
- SBOM/provenance plan implemented or explicitly tracked;
- migration policy and SemVer contract published.
